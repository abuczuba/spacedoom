# Starship

There is no custom `starship.toml` on this workstation. Interactive Fish runs
`starship init fish | source`, using Starship's built-in defaults (observed with
1.27.0). The Fish prompt functions are the preserved fallback when Starship is
unavailable. No configuration is invented or deployed for this application.

To customize a fork, create `~/.config/starship.toml`; see the
[upstream configuration reference](https://starship.rs/config/).
